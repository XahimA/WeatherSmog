Real-time AQI with Visibility & Fog Level Analysis + 10km Pincode Mapping

📊 How It Works

Visibility Classification (4-Level System - Matching Azure):

• AQI ≤ 100: Clear (> 2 km visibility)

• AQI 101-200: Moderate Fog (1-2 km visibility)

• AQI 201-300: Dense Fog (500m-1km visibility)

• AQI > 300: Very Severe Fog (200-500m visibility)

Pincode Mapping: Uses Haversine distance formula to find all pincodes within 10km radius of each monitoring station. CSV export creates one row per pincode (same as Azure daily email).
